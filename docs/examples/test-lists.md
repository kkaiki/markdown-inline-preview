# リスト操作テスト

このファイルでリスト操作機能をテストできます。

## 箇条書きリスト

- アイテム1
- アイテム2
- アイテム3

### ネストされた箇条書き

- 親アイテム
  - 子アイテム1
  - 子アイテム2
    - 孫アイテム

## 番号付きリスト

1. 最初のアイテム
2. 2番目のアイテム
3. 3番目のアイテム

### ネストされた番号付き

1. 親アイテム
  1. 子アイテム1
  2. 子アイテム2
    1. 孫アイテム

## チェックボックス

- [ ] 未完了タスク1
- [ ] 未完了タスク2
- [x] 完了タスク1
- [x] 完了タスク2

### ネストされたチェックボックス

- [ ] 親タスク
  - [ ] 子タスク1
  - [x] 子タスク2
    - [ ] 孫タスク

---

## テスト手順

### 1. リストタイプ変換

1. 上の箇条書きリストを選択
2. `Alt+Cmd+6` を押す
3. 番号付きリストに変換されることを確認

### 2. インデント操作

1. リスト項目にカーソルを置く
2. `Tab` を押してインデントを追加
3. `Shift+Tab` を押してインデントを削除

### 3. スマートEnter

1. `- テスト` と入力
2. Enter を押す
3. 新しい `- ` が追加されることを確認

### 4. 空アイテムでの終了

1. `- ` のみの行（空のリスト項目）にカーソルを置く
2. Enter を押す
3. マーカーが削除されることを確認

### 5. チェックボックストグル

1. チェックボックスの `[ ]` または `[x]` をクリック
2. 状態が切り替わることを確認
3. `Cmd+Enter` でも切り替わることを確認
