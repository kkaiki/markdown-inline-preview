# 目次機能仕様

## 概要

Markdownファイル内の見出しを自動検出し、目次（Table of Contents）を生成・更新する機能。

## マーカー

### 書式

```markdown
/目次
```

または

```markdown
/toc
```

### 条件

- 行頭から始まる
- 他のテキストを含まない
- コードブロック内は無視

## 見出し検出

### 対象

```markdown
# H1 見出し
## H2 見出し
### H3 見出し
#### H4 見出し
##### H5 見出し
###### H6 見出し
```

### 除外条件

- コードブロック内の `#`
- 目次マーカー行自体

## 目次生成

### 出力形式

```markdown
- [見出しテキスト](#スラッグ)
  - [サブ見出し](#サブスラッグ)
    - [サブサブ見出し](#サブサブスラッグ)
```

### インデント

- 最小の見出しレベルを基準
- レベルが1つ深くなるごとに2スペースインデント

### スラッグ生成

```
入力: "Hello World! こんにちは"
出力: "hello-world-こんにちは"
```

ルール:
1. 小文字に変換
2. 英数字、日本語（ひらがな、カタカナ、漢字）、ハイフン、スペースを保持
3. スペースをハイフンに変換
4. 連続するハイフンを1つに

## 自動更新

### トリガー

- 見出し行の変更を検出
- 500msのデバウンス後に実行

### 条件

- `markdownInline.toc.autoUpdate` が `true`
- ドキュメント内に目次マーカーが存在

### 変更検出

```javascript
const hasHeadingChange = event.contentChanges.some(change => {
    const lineText = editor.document.lineAt(change.range.start.line).text;
    return lineText.match(/^#{1,6}\s/) || change.text.match(/^#{1,6}\s/);
});
```

## 手動更新

### コマンド

`markdownInline.updateTableOfContents`

### ショートカット

- Mac: `Cmd+Shift+T`
- Windows/Linux: `Ctrl+Shift+T`

## 設定

| 設定 | 型 | デフォルト | 説明 |
|------|-----|-----------|------|
| `toc.autoUpdate` | boolean | true | 自動更新の有効化 |
| `toc.minLevel` | number | 1 | 目次に含める最小レベル |
| `toc.maxLevel` | number | 6 | 目次に含める最大レベル |

### 設定例

H2〜H4のみを目次に含める:
```json
{
  "markdownInline.toc.minLevel": 2,
  "markdownInline.toc.maxLevel": 4
}
```

## 既存目次の検出

### パターン

```markdown
/目次

- [見出し1](#見出し1)
- [見出し2](#見出し2)

次のコンテンツ...
```

### 検出ルール

1. マーカーの次の行から開始
2. `- [テキスト](#リンク)` 形式の行を目次と認識
3. 空行または非目次行で終了

## エッジケース

### 1. 見出しがない場合

目次を生成せず、メッセージを表示しない（自動モード時）

### 2. マーカーがコードブロック内

```markdown
```markdown
/目次
```
```

→ 無視（目次を生成しない）

### 3. 複数のマーカー

各マーカーに対して個別に目次を生成

### 4. 重複する見出し

同じスラッグが生成されるが、GitHubと同様の動作
（ブラウザが最初のアンカーにジャンプ）

## テストケース

### ケース1: 基本的な目次生成

入力:
```markdown
/目次

# セクション1
## サブセクション1-1
# セクション2
```

期待出力:
```markdown
/目次

- [セクション1](#セクション1)
  - [サブセクション1-1](#サブセクション1-1)
- [セクション2](#セクション2)
```

### ケース2: レベルフィルタリング

設定: `minLevel: 2, maxLevel: 3`

入力:
```markdown
/目次

# H1見出し
## H2見出し
### H3見出し
#### H4見出し
```

期待出力:
```markdown
/目次

- [H2見出し](#h2見出し)
  - [H3見出し](#h3見出し)
```
