# リスト操作仕様

## 概要

Markdownのリスト（箇条書き、番号付き、チェックボックス）の編集操作を効率化する機能。

## リストタイプ

### 1. 箇条書きリスト

```markdown
- アイテム1
- アイテム2
  - ネストされたアイテム
```

マーカー: `-`, `*`, `+`

### 2. 番号付きリスト

```markdown
1. 最初のアイテム
2. 2番目のアイテム
  1. ネストされたアイテム
```

マーカー: `数字.` または `数字)`

### 3. チェックボックス

```markdown
- [ ] 未完了タスク
- [x] 完了タスク
  - [ ] ネストされたタスク
```

マーカー: `- [ ]` または `- [x]`

---

## リストタイプ変換

### コマンド

| コマンド | ショートカット (Mac) | ショートカット (Win) |
|---------|-------------------|-------------------|
| 箇条書きに変換 | `Cmd+Shift+5` | `Ctrl+Shift+5` |
| 番号付きに変換 | `Cmd+Shift+6` | `Ctrl+Shift+6` |
| チェックボックスに変換 | `Cmd+Shift+4` | `Ctrl+Shift+4` |
| 通常テキストに変換 | `Cmd+Shift+0` | `Ctrl+Shift+0` |

### 変換ルール

#### 箇条書きへ

```
入力: 1. アイテム
出力: - アイテム

入力: - [ ] タスク
出力: - タスク

入力: 通常テキスト
出力: - 通常テキスト
```

#### 番号付きへ

```
入力: - アイテム
出力: 1. アイテム

入力: - [ ] タスク
出力: 1. タスク
```

連続する行は自動採番:
```
入力:
- アイテム1
- アイテム2

出力:
1. アイテム1
2. アイテム2
```

#### チェックボックスへ

```
入力: - アイテム
出力: - [ ] アイテム

入力: 1. アイテム
出力: - [ ] アイテム
```

#### 通常テキストへ

```
入力: - アイテム
出力: アイテム

入力: 1. アイテム
出力: アイテム

入力: - [ ] タスク
出力: タスク
```

### インデント保持

変換時にインデントを維持:
```
入力:
- アイテム1
  - ネストされたアイテム

Cmd+Shift+6:
1. アイテム1
  1. ネストされたアイテム
```

## スマートEnter

### 動作マトリックス

| リストタイプ | カーソル位置 | コンテンツ | 動作 |
|------------|------------|----------|------|
| 番号付き | 行末 | あり | 次の番号で継続 |
| 番号付き | 行末 | なし | マーカー削除 |
| チェックボックス | 行末 | あり | 新しいチェックボックス追加 |
| チェックボックス | 行末 | なし | マーカー削除 |
| 箇条書き | 行末 | あり | 通常改行 |
| 箇条書き | 行末 | なし | マーカー削除 |

### 番号付きリストの継続

```
入力: 1. アイテム|  (カーソル位置)
Enter押下後:
1. アイテム
2. |
```

### チェックボックスの継続

```
入力: - [ ] タスク|
Enter押下後:
- [ ] タスク
- [ ] |
```

### 空アイテムでのマーカー削除

```
入力: - [ ] |  (空のチェックボックス)
Enter押下後:
|  (マーカーが削除され、通常行に)
```

## インデント操作

### Tab

| コンテキスト | 動作 |
|------------|------|
| リスト項目 | インデント追加（2スペース） |
| 番号付きリスト | インデント追加 + 再採番 |

### Shift+Tab

| コンテキスト | 動作 |
|------------|------|
| リスト項目 | インデント削除 |
| 番号付きリスト | インデント削除 + 再採番 |

### 番号の再採番

```
変更前:
1. アイテム1
  3. ネストA
  5. ネストB
2. アイテム2

Tab/Shift+Tab後:
1. アイテム1
  1. ネストA
  2. ネストB
2. アイテム2
```

---

## チェックボックストグル

### マウス操作

クリック範囲: `[` から `]` まで（設定で変更可能）

### キーボード操作

`Cmd+Enter` (Mac) / `Ctrl+Enter` (Win)

### 状態遷移

```
[ ] → [x] → [ ] → ...
```

### 装飾

| 状態 | 装飾 |
|------|------|
| `[ ]` | なし |
| `[x]` | 取り消し線 + 透明度低下 |

---

## 複数行選択時の動作

### 変換

選択した全行を一括変換:
```
選択:
- アイテム1
- アイテム2
- アイテム3

Cmd+Shift+6:
1. アイテム1
2. アイテム2
3. アイテム3
```

### インデント

選択した全行を一括インデント/アンインデント

---

## エッジケース

### 1. 混在リスト

```markdown
- 箇条書き
1. 番号付き
- [ ] チェックボックス
```

各行を個別に処理

### 2. コードブロック内

```markdown
```
- これはコードなので変換しない
```
```

コードブロック内は処理をスキップ

### 3. 引用内のリスト

```markdown
> - 引用内のリスト
```

引用マーカーを保持しつつ変換

## テストケース

### ケース1: 基本的な変換

```
入力: - アイテム
操作: Cmd+Shift+6
期待: 1. アイテム
```

### ケース2: インデント保持

```
入力:
  - ネストされたアイテム
操作: Cmd+Shift+4
期待:
  - [ ] ネストされたアイテム
```

### ケース3: 連続行の採番

```
入力:
- アイテム1
- アイテム2
- アイテム3
操作: 全選択 + Cmd+Shift+6
期待:
1. アイテム1
2. アイテム2
3. アイテム3
```
