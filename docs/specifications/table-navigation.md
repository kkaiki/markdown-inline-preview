# テーブルナビゲーション仕様書

## 概要

Markdownテーブル内でのカーソル移動を直感的にするための仕様。

## テーブル構造の例

```
| Header 1 | Header 2 | Header 3 |
|----------|----------|----------|
| Cell A1  | Cell B1  | Cell C1  |
| Cell A2  | Cell B2  | Cell C2  |
```

セルの構造:
```
| Cell A1  |
^         ^
|         └── cellEnd (次の|の位置)
└── cellStart (|の直後)

| Cell A1  |
  ^     ^
  |     └── cellContentEnd (末尾空白の前)
  └── cellContentStart (先頭空白の後、実際の文字の開始位置)
```

---

## 操作一覧

### 1. 上下矢印キー (↑↓)

#### 現在の動作
- VSCodeデフォルト: 単純に上下の行に移動

#### 期待する動作
- **下に移動 (↓)**: 下の行の**同じセル**で、現在セル内と同じ**相対カーソル位置**に移動
- **上に移動 (↑)**: 上の行の**同じセル**で、現在セル内と同じ**相対カーソル位置**に移動
- 移動先セルが短い場合は、そのセルの末尾で止める

#### 例
```
| Header 1 | Header 2 |
           ^カーソルここ（位置13）
              ↓ 押下
| Cell A1  | Cell B1  |
           ^ここに移動（Cell B1 内の同じオフセット位置）
```

---

### 2. 左矢印キー (←) - Cmd+Left / Home

#### 2.1 セル内の途中にカーソルがある場合

**操作**: `Cmd+Left` (Mac) / `Home` (Win)

**動作**: セル内のコンテンツ開始位置に移動

```
| Cell A1  |
      ^カーソルここ
  ↓ Cmd+Left
| Cell A1  |
  ^ここに移動（コンテンツ開始位置）
```

#### 2.2 セル内のコンテンツ開始位置にカーソルがある場合

**操作**: `Cmd+Left` (Mac) / `Home` (Win)

**動作**: セルの左端（|の直後）に移動

```
| Cell A1  |
  ^カーソルここ（コンテンツ開始位置）
  ↓ Cmd+Left
| Cell A1  |
 ^ここに移動（|の直後）
```

#### 2.3 セルの左端（|の直後）にカーソルがある場合

**操作**: `Cmd+Left` (Mac) / `Home` (Win)

**動作**: 左隣のセルの**コンテンツ末尾**に移動
- 左隣のセルが空の場合: 左隣のセルのコンテンツ開始位置に移動
- 最初のセルの場合: 行頭（位置0）に移動

```
| Cell A1  | Cell B1  |
           ^カーソルここ（セル左端）
  ↓ Cmd+Left
| Cell A1  | Cell B1  |
        ^ここに移動（Cell A1のコンテンツ末尾）
```

**左セルが空の場合**:
```
|          | Cell B1  |
           ^カーソルここ
  ↓ Cmd+Left
|          | Cell B1  |
 ^ここに移動（空セルの左端）
```

**最初のセルの左端の場合**:
```
| Cell A1  | Cell B1  |
 ^カーソルここ（最初のセル左端）
  ↓ Cmd+Left
| Cell A1  | Cell B1  |
^ここに移動（行頭、最初の|の位置）
```

---

### 3. 右矢印キー (→) - Cmd+Right / End

#### 3.1 セル内の途中にカーソルがある場合

**操作**: `Cmd+Right` (Mac) / `End` (Win)

**動作**: セル内のコンテンツ末尾に移動

```
| Cell A1  |
  ^カーソルここ
  ↓ Cmd+Right
| Cell A1  |
        ^ここに移動（コンテンツ末尾）
```

#### 3.2 セル内のコンテンツ末尾にカーソルがある場合

**操作**: `Cmd+Right` (Mac) / `End` (Win)

**動作**: セルの右端（|の直前）に移動

```
| Cell A1  |
        ^カーソルここ（コンテンツ末尾）
  ↓ Cmd+Right
| Cell A1  |
         ^ここに移動（|の直前）
```

#### 3.3 セルの右端（|の直前）にカーソルがある場合

**操作**: `Cmd+Right` (Mac) / `End` (Win)

**動作**: 右隣のセルの**コンテンツ開始位置**に移動
- 最後のセルの場合: 行末に移動

```
| Cell A1  | Cell B1  |
         ^カーソルここ（セル右端）
  ↓ Cmd+Right
| Cell A1  | Cell B1  |
            ^ここに移動（Cell B1のコンテンツ開始位置）
```

---

### 4. Tab キー

#### 現在の動作
- インデント追加（リスト用）

#### 期待する動作（テーブル内）
- **Tab**: 右隣のセルのコンテンツ開始位置に移動
- **Shift+Tab**: 左隣のセルのコンテンツ開始位置に移動

```
| Cell A1  | Cell B1  |
    ^カーソルここ
  ↓ Tab
| Cell A1  | Cell B1  |
            ^ここに移動
```

---

### 5. 選択操作 (Shift + 移動キー)

#### 5.1 Shift+Cmd+Left

**セル内の途中から**: カーソル位置からコンテンツ開始位置まで選択

```
| Cell A1  |
      ^カーソルここ
  ↓ Shift+Cmd+Left
| Cell A1  |
  ^^^^選択範囲
```

#### 5.2 連続してShift+Cmd+Left

1回目: コンテンツ開始位置まで選択
2回目: セル左端まで選択を拡張
3回目: 左隣のセル末尾まで選択を拡張

---

## 状態遷移図

### Cmd+Left の状態遷移

```
[セル内の任意位置]
       │
       ↓ Cmd+Left
[セル内コンテンツ開始位置]
       │
       ↓ Cmd+Left
[セル左端（|の直後）]
       │
       ↓ Cmd+Left
[左セルのコンテンツ末尾] ←── 左セルが空なら [左セルの左端]
       │
       ↓ Cmd+Left (左セルの左端から)
[さらに左のセル...] または [行頭]
```

## テストケース

### テストケース 1: 基本的なセル内移動
```
入力: | Hello World |
カーソル位置: 8 (Worldの'o')
操作: Cmd+Left
期待結果: カーソル位置 2 ('H'の位置)
```

### テストケース 2: コンテンツ開始位置からセル左端へ
```
入力: | Hello World |
カーソル位置: 2 ('H'の位置)
操作: Cmd+Left
期待結果: カーソル位置 1 (|の直後)
```

### テストケース 3: セル左端から左セルへ
```
入力: | Cell A | Cell B |
カーソル位置: 9 (Cell Bのセル左端、|の直後)
操作: Cmd+Left
期待結果: カーソル位置 7 (Cell Aの'A'の後ろ)
```

### テストケース 4: 空セルの処理
```
入力: |        | Cell B |
カーソル位置: 10 (Cell Bのセル左端)
操作: Cmd+Left
期待結果: カーソル位置 1 (空セルの左端)
```

### テストケース 5: 最初のセルから行頭へ
```
入力: | Cell A | Cell B |
カーソル位置: 1 (最初のセルの左端)
操作: Cmd+Left
期待結果: カーソル位置 0 (行頭)
```
