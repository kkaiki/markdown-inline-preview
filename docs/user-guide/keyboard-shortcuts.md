# キーボードショートカット一覧

## 基本操作

| 機能 | Mac | Windows/Linux | 説明 |
|------|-----|---------------|------|
| スマートEnter | `Enter` | `Enter` | リスト継続・終了 |
| チェックボックストグル | `Cmd+Enter` | `Ctrl+Enter` | チェック状態を切り替え |
| インデント追加 | `Tab` | `Tab` | リスト項目をインデント |
| インデント削除 | `Shift+Tab` | `Shift+Tab` | インデントを解除 |

## リストタイプ変換

| 機能 | Mac | Windows/Linux | 説明 |
|------|-----|---------------|------|
| 箇条書きに変換 | `Alt+Cmd+5` | `Alt+Ctrl+5` | `- アイテム` 形式 |
| 番号付きに変換 | `Alt+Cmd+6` | `Alt+Ctrl+6` | `1. アイテム` 形式 |
| チェックボックスに変換 | `Alt+Cmd+4` | `Alt+Ctrl+4` | `- [ ] タスク` 形式 |
| 通常テキストに変換 | `Alt+Cmd+0` | `Alt+Ctrl+0` | マーカーを削除 |

## カーソル移動

| 機能 | Mac | Windows/Linux | 説明 |
|------|-----|---------------|------|
| スマート左移動 | `Cmd+Left` | `Home` | コンテンツ開始位置に移動 |
| スマート右移動 | `Cmd+Right` | `End` | コンテンツ末尾または次のセルへ移動 |
| スマート上移動 | `Up` | `Up` | テーブルでは同じ列位置に移動 |
| スマート下移動 | `Down` | `Down` | テーブルでは同じ列位置に移動 |
| スマート左選択 | `Shift+Cmd+Left` | `Shift+Home` | コンテンツ開始位置まで選択 |
| コンテキスト全選択 | `Cmd+A` | `Ctrl+A` | 段階的に選択範囲を拡大 |

## テーブル操作

| 機能 | Mac | Windows/Linux | 説明 |
|------|-----|---------------|------|
| セル内左端 | `Cmd+Left` | `Home` | セル内の先頭へ |
| セル内右端 | `Cmd+Right` | `End` | セル内の末尾へ |
| 同じ列で上へ | `Up` | `Up` | テーブル内で同じ列へ移動 |
| 同じ列で下へ | `Down` | `Down` | テーブル内で同じ列へ移動 |

注: `tableNavigateRight` と `tableNavigateLeft` コマンドは存在しますが、現状は既定のキーバインドがありません。

## コンテキスト別の動作

### Enter キーの動作

| コンテキスト | 動作 |
|-------------|------|
| 番号付きリスト | 次の番号で継続 |
| チェックボックス | 新しいチェックボックスを追加 |
| 箇条書き | 通常の改行 |
| 空のリスト項目 | マーカーを削除 |
| コードブロック内 | 通常の改行 |

### Cmd+Left の動作

| コンテキスト | 動作 |
|-------------|------|
| 通常テキスト | 行頭に移動 |
| リスト | マーカーの後ろに移動 |
| 見出し | `#` の後ろに移動 |
| テーブルセル | セル内コンテンツ開始位置に移動 |
| 引用 | `>` の後ろに移動 |

### Tab キーの動作

| コンテキスト | 動作 |
|-------------|------|
| リスト項目 | インデント追加 |
| テーブルセル | コンテキストに応じた移動またはインデント |
| 通常テキスト | タブ文字を挿入 |

## ショートカットのカスタマイズ

VSCodeのキーボードショートカット設定（`Cmd+K Cmd+S`）で変更可能。

### 例: Enterキーの競合解決

他のMarkdown拡張機能と競合する場合:

```json
// keybindings.json
[
  {
    "key": "enter",
    "command": "markdownInline.smartEnter",
    "when": "editorTextFocus && editorLangId == markdown && !suggestWidgetVisible"
  },
  {
    "key": "enter",
    "command": "-markdown.extension.onEnterKey",
    "when": "editorTextFocus && editorLangId == markdown"
  }
]
```
