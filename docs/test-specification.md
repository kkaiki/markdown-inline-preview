# Preview エディタ テスト仕様書

> このドキュメントは Preview（Milkdown WYSIWYG）モードで行う全操作のテストケースを網羅する。  
> 「✅ 実装済み」= 既存テストあり、「🆕 追加予定」= 未実装のテストケース。  
> ファイルパスは `test/webview/` または `test/suite/` 以下。

> **第1次実装（2026-06-28）で 42 ケースを追加し、テスト総数は 719 → 761 になった。**
> 追加分は以下のファイル（すべて緑）:
> - `imageIsolation.integration.test.ts`（画像分離プラグイン 5件）
> - `serializeRoundtrip.integration.test.ts`（Markdown round-trip 15件）
> - `paragraphEnter.integration.test.ts`（段落 Enter/Shift+Enter 5件）
> - `listEnter.integration.test.ts`（リスト Enter 継続/離脱 5件）
> - `blockConvert.integration.test.ts`（ブロック変換 2/3/4/0 とトグル 7件）
> - `inlineFormatting.integration.test.ts`（Cmd+B/I トグル 5件）
>
> この実装に伴い、`previewKeymapPlugin.ts` に2点の挙動改善を入れた（Notion 準拠）:
> 1. **Cmd+Opt+0** がリスト項目内では段落へ持ち上げる（旧: 見出し/コードのみ本文化）
> 2. **同じ見出しレベルの再押下**で段落へ戻る（トグル）
