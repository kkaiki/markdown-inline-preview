# アーカイブ: Preview モード時代の仕様書

ここにある文書は、**削除された Preview モード（Milkdown / ProseMirror ベースの WYSIWYG）**
とその時代の Raw モードについて書かれたものです。

Preview モードは 2026-08-05 に Live モード（CodeMirror 6）へ一本化され、コードとテストは
すべて削除されました。文書は「なぜその挙動にしたか」の経緯として残していますが、
**現行の実装を説明するものではありません**。現行の仕様は
[docs/specifications/live-mode/](../../specifications/live-mode/) を参照してください。

Raw モードについて書かれた部分は今も有効な場合があります。参照するときは、
記述が Preview（webview / Milkdown）の話か Raw（VS Code 標準エディタ）の話かを
確認してください。
